# 家内多维差异构造字典（均值 · 标准差 · 性别差 · 长幼差）

返回 [[wiki/index|Wiki 路由目录]]

以明确报告者的“父母—波次”为单位，区分合格成年健在子女数 `Keligible` 与非缺失观测数 `m = Kobs`：

| 指标 | 定义 | 防混红线 |
|---|---|---|
| **平均水平** | `sum(Y) / m`（`m >= 1`） | 缺失不默认填 0；家庭总额与子女均值分开命名 |
| **样本标准差（绝对离散）** | `sqrt(sum((Y - mean)^2) / (m - 1))`（`m >= 2`） | 不可与旧代码中 `100 * raw_sd / mean` 的相对离散指标混称 |
| **有符号性别差** | `儿子有效均值 − 女儿有效均值` | 要求儿女两组均有有效观测，单性别家庭不填 0 |
| **长幼差（两端差 vs 其余均值差）** | 候选 A：`最年长 − 最年幼`；历史对照 B：`最年长 − 其余子女均值` | 两个不同估计对象必须分别命名，处理双胞胎出生并列 |

> "旧平行潜增长脚本中的 SD 分支实际计算为 `100 * raw_sd / wave_mean` 并按基期标准化（相对离散系数），而新课题拟采用的样本标准差 `sqrt(sum((Y-mean)^2)/(m-1))` 属于绝对离散度" — raw/demo/panel_survey_notes.md
